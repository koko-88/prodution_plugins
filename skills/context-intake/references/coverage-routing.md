# Evidence routes and explicit exclusions

## Provider prohibition

Firecrawl's retrieval, provider, document-upload, browser, crawl, monitoring,
research-job and feedback routes are all excluded by the caller's explicit
prohibition. Reading their local instructions for provenance does not authorize
executing any operation, including supposedly free discovery or account checks.
Use a permitted source route or leave a typed external-fact gap. This entry does
not import the provider's focused sales, design or research workflows.

## Existing state interfaces

GSD MCP exposes command dispatch and `.planning` state reads/writes. A named,
already existing state document may be a context pointer. Command dispatch,
scaffolding, state mutation and workflow advancement remain in the GSD factory.
MCP is an interface to that lifecycle, not another intake methodology. Shared
intake never requires `.planning` or the server to be installed.

## Connected owner documents

Ground a connected document's identity before attributing a requirement. Preserve
the file ID/URL, owner, scope and relevant revision; an accessible file is not
automatically authoritative for every claim. The Google Drive router contributes
file discovery and metadata-aware retrieval. Its editing, import/export, comments,
sharing and file-organization routes remain specialist work. No stakeholder
message or file mutation follows from intake authorization.

GitHub, Linear, Drive and browser surfaces are optional source locations. Tool
metadata establishes an advertised interface, not authentication, relevant content
coverage or a verified result. Broad searches, browser automation and connector
writes remain downstream. Missing access becomes a routed gap.

## Official product documentation

The installed OpenAI Docs skill is a specialist source-selection workflow for
OpenAI questions. Preserve an explicitly requested product/model and use its
official sources when that fact is needed. Do not turn generic intake into a
model migration, product setup or API-backed implementation. Its own branching
references stay within that specialist workflow.

## Discovery-only records

Empty directories and stale installation references in the prior audit describe
discovery outcomes, not unimplemented interview methods. Retain their historical
scope and accessibility limits in `audit-coverage.json`. Optional installation
recommendations, such as OpenSpec, are not imported methods. Do not describe them
as installed, active or semantically covered.
