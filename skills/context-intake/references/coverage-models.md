# Model and specification variants

Select a GSD or ProductShape section for its specific scenario, evidence or host distinction. For the separate Spec Kit algorithms and project policies, read [Spec Kit variants](coverage-speckit.md).

Search for the named variant ID and read that section; do not load every source or run an upstream lifecycle. Source IDs resolve to exact paths, hashes, aliases and version evidence in the maintenance ledger; the ledger is not a runtime dependency.

All methods retain the shared policy: one consumer-relative handoff, actual owner authority, proposed versus accepted choices, proportionate questions and typed acquisition gaps. No stack, tracker, .planning tree, model fan-out, installation or provider operation is implied.
